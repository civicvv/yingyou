# 英语整句打字训练设计

面向 15–28 岁英语备考用户，首版支持四级、六级、雅思学术类与托福 iBT。用户先选目标，可通过词汇量测试获得起始建议，也可直接练。训练保留「看中文 → 敲英文 → 词级反馈 → 整句判分 → 讲解」。定制题库结合考试目标、词汇诊断与练习表现出题。

## 开发顺序

1. P0 先建立 Vue、Spring Boot、PostgreSQL 骨架、访客会话和题库迁移。用四级少量原创题验证「课节 → 打字 → 判分 → 讲解 → 结果」闭环。
2. P0 接入词汇测评与定制选题。贯通目标选择、分档、首次定制、首答表现调档、换目标与刷新恢复。词汇数值经过试测校准后开放展示。
3. P0 发布前扩齐四个考试路径和通用基础的内容覆盖，验证游客可在桌面与手机完成测评和练习，也可跳过测评直接练。
4. P1 上线账号鉴权、访客学习记录转移、账号学习概览及课程简易发布工具。
5. P2 上线错题本，复用练习组件与判分服务，从课程与定制练习的历史事实回填。

P0 验收覆盖刷新续答、网络重试、双击提交、选题难度调整和题量不足。测评、练习与进度均按当前访客或账号保存。训练难度和词汇档基于项目规则，校准后可换版。
