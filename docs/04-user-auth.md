# 用户管理与鉴权

## P0 访客

课程目录公开可读。首次保存考试目标、开始练习或开始词汇测评时，Vue 先获取 CSRF 凭据，再在需要时建立访客会话。后端生成随机学习者 ID，并用服务端会话关联。浏览器通过 HttpOnly Cookie 维持身份，练习、测评、偏好与进度均按该身份隔离。访客在同一浏览器刷新后能继续，清除站点数据或会话过期后需重新开始。首版访客会话空闲期限拟设 7 天，账户有效期见下。

用户范围涵盖 15–17 岁。P0 仅保存学习所需的目标、作答和结果，入门流程不收集出生日期、学校或联系方式。测评结果默认仅本人可见，用户可切换目标、调整难度或跳过诊断。公开注册前明确部署地区适用的未成年人告知、数据保留与删除流程。日志仅记录聚合所需事件和技术字段。

## P1 账号

项目默认采用邮箱与密码，注册需邮箱确认。首次实现也可用本地邮件收件箱完成端到端联调，生产发信服务在上线前配置。短信验证码和微信登录可在有相应服务配置后单独接入。新项目登录与目标站调研登录各自独立。

- 注册提交邮箱、密码、昵称和条款版本。待验证账号无法登录。发送、重发、登录和重置按 IP 与账号维度限流，公开响应尽量降低账号枚举信息。
- 使用 Spring Security `PasswordEncoder` 的 Argon2id 配置保存密码散列。邮箱验证及密码重置用随机一次性令牌，服务端存摘要、用途、到期时间与使用时间。重置成功后撤销既有账号会话。
- 登录时轮换会话 ID。生产 Cookie 使用 Secure、HttpOnly、SameSite=Lax，账号会话拟设 24 小时空闲期限。所有写操作验证 CSRF，Vue 从同源会话引导接口取得令牌，登录或退出后重新拉取。登出销毁会话。
- 管理权限由服务端授予并校验。练习、错题及结果均从当前会话取学习者身份，再校验资源归属。退出后清除页面内账号数据和旧身份的本地草稿。

## 数据归属与登录迁移

`learner` 保存稳定身份、类型、有效状态及迁移归属。`user_account` 与账号学习者一对一，保存邮箱规范值、验证状态、密码散列、昵称、权限、条款接受记录及时间。邮箱规范值唯一。审核、授权及状态由管理员路径维护。

只有成功登录且同时持有有效访客会话时执行迁移。登录事务锁定访客与账号学习者，转移练习和测评会话及所关联的事实。同一课节、同一定制目标或词汇测评出现两个进行中会话时，按最近有效操作保留一个，另一个置为 `ABANDONED` 并保留历史记录。先关闭冲突会话，再更新所属身份。双方已完成的诊断均保留，以完成时间和 ID 选最新结果。账号已有备考目标和手动难度时保留账号设置，否则继承访客设置。按迁移事实重算课程进度、定制难度和已上线的错题投影。标记原访客已迁移，事务提交后轮换会话并绑定账号。重复登录可安全重试，同一学习者行锁使原访客的并发写请求失效。已有本地草稿随旧身份关闭。

## 主要接口

| 方法与路径 | 用途 |
| --- | --- |
| `GET /auth/session` | 获取匿名、访客或账号状态及 CSRF 引导数据 |
| `POST /auth/guest` | 建立访客身份，已有登录时返回当前身份 |
| `POST /auth/register`、`POST /auth/verify-email` | 注册和确认邮箱 |
| `POST /auth/login`、`POST /auth/logout` | 登录以及注销当前会话 |
| `POST /auth/password-reset-requests`、`POST /auth/password-resets` | 请求并完成密码重置 |
| `GET /me`、`PATCH /me` | 查询个人资料和更新昵称 |

验收包括跨账号 ID 隔离、过期会话和 CSRF 拒绝、登录轮换、双端续练、邮箱令牌只能用一次、迁移冲突不会重复计数。账号注销的数据保留期和运营处理流程在公开注册上线前确定。
