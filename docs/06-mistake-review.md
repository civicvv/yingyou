# 错题管理

错题本为每个学习者保存待复练的句子。P2 使用 P0 课程和定制练习的整句作答、提示与跳过事实。词汇测评错答留在测评数据内，用于诊断。访客在身份有效期间可复练，P1 账号可跨设备同步。

## 收录与状态

| 练习行为 | 错题效果 |
| --- | --- |
| 课程或定制中首次或再次出现正式整句错答 | 建立或刷新 `ACTIVE`，每题每个练习会话按一次失误计数 |
| 使用首词提示或查看参考答案 | 本题终结时收录为辅助训练，未终结前作为练习事实保留 |
| 跳过 | 立即收录，同一题项已收录时合并原因 |
| 课程或定制中无帮助答对 | 保留既有错题状态，用户可在错题专项中验证掌握 |
| 错题复练中首答正确且无帮助 | 将该版错题标记 `MASTERED` |
| 错题复练中有正式错答、跳过或用帮助 | 继续保留为 `ACTIVE`，更新最近事件。词级预检只用于训练反馈。 |
| 已掌握后在课程或定制中再次符合收录规则 | 重新激活，保留首次收录时间和累计次数 |

## 页面和复练

`/review` 默认展示待复练项，按最近失误倒序，可按考试目标、课程和掌握状态筛选。卡片显示中文、来源、收录原因、失误次数和最近时间。复练时初始隐藏英文，允许从筛选结果或勾选集开始。本批最多 20 题，按最近失误倒序与稳定 ID 排序，创建时固定版本。每位学习者最多保留一个进行中复习会话。已有会话时返回其续练入口。页内结果展示本次掌握数、继续练习数和跳过数。

修订题库时，错题复练优先使用最后一次失误的题目版本；下架后仍可用已授权的历史版本。若运营将某版本标成不可再出题，列表保留历史状态并提示不可选。

## 数据、事务与 API

- `mistake_entry` 以 `(learner_id, sentence_id)` 唯一，保存状态、最近失误题目版本、来源、事件时间、首次时间和累计失误题项数。通过事件事实筛选课程或考试目标。课程来源使用课程 ID 与当时考试路径，定制来源只用批次的考试目标。
- `mistake_event` 以 `(learner_id, practice_item_id, event_type)` 唯一，存所需事实及时间。一次题项同时有错误和跳过时合并原因，按题项去重。正误事件与练习写操作同事务记录，将投影按事件顺序更新。
- `review` 创建会话时为每个题项记录错题行修订号。判定通过时执行条件更新，若期间该错题已有更新失误或版本更替，则保留最新待复练状态。账号迁移后按事实顺序重建，事件时间相同以稳定事件 ID 排序。
- P2 上线时按批扫描课程与定制题项和尝试记录。依据原事件时间回填，依赖唯一约束允许重复执行。回填与新写入都调用同一事件归并函数，旧事件不会覆盖更新事件的状态。

| 方法与路径 | 契约 |
| --- | --- |
| `GET /me/mistakes?status=ACTIVE&courseId=...&examTrack=...` | 当前学习者分页查询，游标为最近失误时间与条目 ID |
| `POST /review/sessions` | `{requestId, mistakeIds?, courseId?, examTrack?}`，输入条目必须归属当前学习者且可复练。空结果返回 422 |
| `GET /practice/sessions/{id}/result` | 使用共用结果 API，复练结果追加每题的掌握变化 |

验收覆盖一次题多次答错只累加一次、多课节同题去重、先辅助后答对仍需复练、专项首答正确自动掌握、旧复练无法清除并发新错题、网络重试与历史回填幂等。
