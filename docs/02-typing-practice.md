# 基础功能 · 中译英整句练习

## 页面与操作

入口为课节页的「开始练习」「继续练习」，或测评结果及学习页的「定制练习」。练习页为 `/practice/:sessionId`，结果页为 `/practice/:sessionId/result`。原创界面采用浅色阅读区和暖色强调，顺序为课节名或考试路径与进度、中文题目、英文输入及词级反馈、带文字的操作按钮。移动端随软键盘调整，保证输入框和提交按钮可用。

1. 进入页面后显示中文提示与必要语境，题卡显示「第 1/5 题」。使用一个原生英文输入控件，支持粘贴、退格和选择文本，反馈区按词展示已匹配、需要修改和待检查。空格完成一个词后即可预检。
2. 点击「检查」或在输入框按 Enter 提交整句。组合输入状态下忽略 Enter，检查 `isComposing` 及组合事件。提交中锁定写按钮，保留输入和请求号供重试。
3. 答错时保留正文，提示「和目标表达还不一致」，显示首个词级编辑差异的位置与类型，例如「第 3 个词可能拼错」。缺词、额外词和替换采用同一组词级对齐规则。用户可以修改后再次提交。
4. 「给个提示」揭示规范答案的首词，每题可用一次。第二个辅助动作是「看参考答案」，展开规范答案和简短讲解，允许用户继续作答。答对后进入题内讲解，展示规范答案、可用的句子成分和语法标签，预览下一题中文。
5. 「跳过」终结本题并进入讲解。题目终结后聚焦下一题按钮，按 Enter 或点击按钮继续。忽略长按产生的重复键事件，避免一次回车同时提交和切题。末题按钮改为「查看本节结果」。结果显示本节题数、独立完成数、辅助完成数、跳过数与首答正确率。
6. 反馈区使用 `aria-live` 和文字标记。下一题后将焦点移回输入区，错误和正确状态同时有文字与样式。移动端关闭可控的自动更正与自动首字母大写。前端草稿按会话与题目版本保存在当前标签页 `sessionStorage`，仅在对应题回填，切题后清除上题草稿。

## 词级预检

- Vue 监听原生输入事件，在空白分隔符处提取已经输入完的前缀。组合输入期间暂停预检，粘贴后只对已经有结束分隔符的前缀请求一次。200 ms 防抖合并连续输入。光标编辑、退格或切题使旧反馈失效，异步响应只在当前会话、题项、修订号和已完词对应的文本均匹配时渲染。
- Spring 按判分版本归一化已完词，再与规范答案及所有获准变体按词对齐起始部分。采用匹配词数最长的候选。返回连续匹配的词数和第一个待修改词的位置，不返回剩余答案、候选词或隐藏词数。位于首个差异之后的词保留待检查状态。
- 词以空白切分。预检接受候选最后一词的句末标点宽容规则，候选中间词仍要求保留句中标点。词级反馈用来指导修改；正式整句匹配仍由 `SUBMIT` 决定，避免完整但词序不同的变体被前端规则误判。
- 预检校验会话归属、当前题项与修订号，并限制频率和输入长度。预检不产生作答事实、修订号、进度或错题。预检失败时保留输入，用户仍可提交整句。完整参考答案仅通过提示或讲解按其可见范围返回。

## 服务端状态机

| 主状态 | 操作 | 持久化结果 |
| --- | --- | --- |
| `OPEN` | 首词提示、看参考答案 | 分别记录 `hintUsed` 或 `answerRevealed`。两者任一出现，本题后续答对均属辅助完成。看答案后仍可输入。 |
| `OPEN` | 提交正确或错误答案 | 新增 `attempt`。答错保留 `OPEN` 并更新最近判分反馈。答对锁定为 `PASSED_INDEPENDENT` 或 `PASSED_ASSISTED`。 |
| `OPEN` | 跳过 | 锁定为 `SKIPPED`。跳过没有作答事实。 |
| 题目已终结 | 下一题 | 移动当前题序。末题则将会话置为 `COMPLETED` 并生成结果。 |
| 会话已完成 | 读取 | 返回结果。已成功的写请求仍可按请求号重放，其他写请求返回冲突。 |

独立完成允许前面有错答，前提是作答成功前未用帮助。首答正确只认第一次有效提交且首次提交前未使用帮助。重复获取同等级提示返回已生成的提示状态，旧页刷新后从服务端恢复最近判分、提示和终结状态。

## 判分规则 v1

1. 后端校验输入非空，原始输入最多 500 个 Unicode 码点。经规范化后若为空，同样返回表单错误且无作答记录。
2. 对输入与题库的每个候选答案做同样的规范化。NFKC 归一化，弯撇号统一为 ASCII 撇号，Unicode 空白连续段合为普通空格并去除首尾空白，再以 `Locale.ROOT` 转小写，最后去掉末尾连续的 `.`、`!`、`?` 及其前空白。保留词内撇号、连字符和句中标点。
3. 与规范化后的参考答案或经人工审核的等价答案精确匹配即为正确。缩写与完整式分别登记。默认不做编辑距离容错或通用语义评分。错答反馈按词级最小编辑距离选择候选，距离相同优先规范答案，再按替代答案发布顺序。只给差异位置和操作类型。
4. 每个会话固定 `gradingVersion`。题目变体匹配规则随不可变题目版本保存，重试和历史详情沿用当时版本。

| 中文题目 | 输入例 | 预期 |
| --- | --- | --- |
| 我今晚会给你回电话。 | `  I’LL   CALL YOU BACK TONIGHT！ ` | 正确，假设规范答案为 `I'll call you back tonight.` |
| 同上 | `I will call you back tonight.` | 正确，前提是题库已审核并登记此变体 |
| 同上 | `Ill call you back tonight.` | 错误，保留词内撇号差异 |
| 同上 | `I’ll call back you tonight.` | 错误，提示词序或相应的词级编辑位置 |
| 同上 | 全空白，或仅输入 `?!` | 表单错误，题目状态和作答次数保持原值 |

## 接口与数据

| 方法与路径 | 契约 |
| --- | --- |
| `POST /practice/sessions` | 入参 `lessonId, requestId`。同学习者同课节返回进行中的会话，否则用当前发布版本创建。定制与错题场景通过各自的创建入口共用练习会话。 |
| `GET /practice/sessions/{id}` | 返回 `revision, status, position, total, currentItem, feedback`。当前题 DTO 含题项 ID、中文、语境和状态。完整答案仅在本题已看答案或已终结时填入反馈。 |
| `POST /practice/sessions/{id}/prefix-check` | `{revision,itemId,text}`，文本为已结束的词前缀。返回 `{revision,itemId,matchedCount,firstMismatchIndex}`，索引从 0 开始，无差异时为 null。只读预检，无需写操作请求号。 |
| `POST /practice/sessions/{id}/commands` | `{requestId, revision, itemId, action, text?}`。动作取 `SUBMIT`、`HINT`、`REVEAL`、`SKIP`、`NEXT`。成功返回新的会话视图，对 SUBMIT 额外返回 `attemptId` 与反馈。 |
| `GET /practice/sessions/{id}/result` | 返回完成时快照与题目级结果。进行中返回 409。 |

- `practice_session` 保存所属学习者、来源 `LESSON/PERSONALIZED/REVIEW`、汇总状态、当前题序、修订号与判分版本。仅课程会话填写课节版本；定制批次所用目标和诊断见[定制练习](09-personalized-practice.md)。按场景加部分唯一索引，分别约束进行中的课程课节、定制目标与专项复练。
- `practice_item` 保存 `session_id, position, sentence_version_id, status, hint_used, answer_revealed` 和终结时间。`(session_id, position)` 唯一。
- `attempt` 保存题项、序号、原文、匹配结果、提交时是否已用辅助和差异元数据。`(practice_item_id, ordinal)` 唯一。
- `practice_command` 保存 `(session_id, request_id)` 唯一键、规范化请求体摘要和当时响应。创建会话的幂等单独按 `learner_id + request_id` 记录，并靠会话唯一约束处理并发创建。
- 终结态题项的会话视图附 `feedback.explanation` 和可选的 `nextPreview.position, nextPreview.promptZh`。预览只包含下一题序号和中文。进入下一题前刷新仍显示本题讲解。
- P0 验收覆盖预检准确、变体前缀、编辑后旧响应被丢弃、预检失败仍可提交、辅助作答、输入法 Enter、双标签页冲突、跳过末题、讲解刷新和移动端操作。超时重试时错误次数和进度只更新一次。
