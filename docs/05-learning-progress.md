# 学习进度与统计

## 展示位置

- 我的课程显示最近练习、已完成课节与继续练习按钮。课节行显示未开始、进行中或已完成。已完成后再次练习仍可找到上次结果。
- 练习页显示当前题序与总题数。题目终结后显示本节已处理题数。单题讲解可预览下一题中文。
- 课节结果展示独立完成、辅助完成、跳过和首答正确率。学习记录 P1 支持按课程查询已完成的会话。训练时间的有效时长统计放到 P1，首版以题数和正确率验收。
- P0 定制练习页按考试目标显示最新词汇档、诊断日期、当前整句难度与本批首答正确率，并提供下一批入口。词汇档表示识词结果，整句难度表示练习设置。测评及定制练习各自保留结果，课程完成率只聚合课程会话。

## 指标定义

| 指标 | 计算 |
| --- | --- |
| 本节已处理 | `PASSED_INDEPENDENT + PASSED_ASSISTED + SKIPPED` |
| 课节完成 | 该课节至少有一次课程会话进入 `COMPLETED`。中途退出保留进度，末题终结后由下一步操作提交结果 |
| 课程完成率 | 当前已发布课节中已完成的课节数 ÷ 当前已发布课节数。课节内容更新保留该稳定课节的历史完成标记，新加课节会进入分母 |
| 本节首答正确率 | 首次有效提交正确且首次提交前未用辅助的题数 ÷ 本节总题数。跳过、未独立首答的题均为零 |
| 继续练习 | 当前学习者同课节的活动课程会话。跨课节入口选择最近有有效操作的活动会话 |

课程完成表示用户走完题目，单题掌握情况由独立、辅助、跳过及首答正确率呈现。跨版本报表带 `lessonVersionId`。默认展示最近一次完成结果，重新练习进行中时同时显示续练入口。错题专项复练使用独立场景。

## 存储与更新

`learner_lesson_progress` 以 `(learner_id, lesson_id)` 唯一，保存最近活动会话、最近完成会话、首次完成时间和最近练习时间。更新会话状态、结果快照与课节进度在同一数据库事务中处理。没有结果文件时，可根据题项终结状态和作答事实重建。P1 有效时长拟采用仅记录可见前台的累计活动片段，按服务端接收周期去重、限制单片长度，并与会话总历时分开显示。

进度读接口为 `GET /me/progress?courseId=...` 和 `GET /me/practice-history?courseId=...`，后者 P1 按完成时间与会话 ID 游标分页。课节结果的题数和首答正确率分母都以会话创建时固定的题目集合计算。

定制结果复用首答正确定义，并按考试目标、题目难度和主要技能筛选用于调档的事实。用于统计和用于调档的样本范围各自保存。整批成绩涵盖所有题；用于调档的窗口只计算当前难度的去重题目。[定制练习与推荐](09-personalized-practice.md)

示例验收。一节 5 题，3 题首答正确、1 题答错后查看答案再答对、1 题跳过。最终独立 3、辅助 1、跳过 1、首答正确率 60%，课节已完成。重复请求保持该结果；复练同课后，上次结果仍可打开。
