# 课程与题库

## 页面与范围

- `/courses` 展示已发布课程和「继续练习」入口。`/courses/:courseId` 展示课节和各节状态。课程详情页的课节在首版全部可练。
- 「我的课程」P0 显示当前身份练过的课程，以最近学习时间排序。有进行中会话时显示继续入口。P1 可增加手动加入及移除，个人课程进度保留。
- P0 先用四级示例课和原创种子验证练习，首发按四个考试目标与通用基础发布。每条路径的题量、技能标签、难度规则见[备考内容](07-exam-content.md)。P1 提供运营侧草稿、校验预览、发布和下架。已有进行中的练习允许继续访问其版本。

## 数据与版本

| 表 | 关键字段 |
| --- | --- |
| `course` | 稳定 ID、所属考试路径、标题、简介、状态、排序 |
| `lesson` | 稳定 ID、课程 ID、标题、排序、当前已发布版本 ID |
| `lesson_version` | 课节 ID、版本号、创建和发布时间，课节内版本号唯一 |
| `sentence` | 稳定句子 ID。保留相同 ID 表示修订同一学习目标，更换学习目标则创建新 ID |
| `sentence_version` | 句子 ID、版本号、中文、必要语境、规范英文、审核过的答案变体、有序讲解段、中文讲解、语法标签及备考元数据 |
| `lesson_version_item` | 课节版本 ID、序号、题目版本 ID。同一课节版本内序号唯一，稳定句子 ID 不重复 |

讲解段用有序 JSON 数组，字段为 `text, role, gloss`。可选段只在有对应内容时显示。讲解视图按作者提供的边界展示，完整英文始终使用规范英文直接显示。发布检查覆盖空白、顺序、规范化后重复答案、文本长度、讲解段与规范英文的对应关系、来源与授权。每题显式维护缩写、同义表达差异和教学目标，题库使用原创或取得授权的内容。

发布在同一事务写入新版本并更新课节指针。开始练习时快照有序题目版本。新会话使用最新已发布版本，进行中会话按已有版本继续，历史结果仍能解释当时判分。删除草稿与下架课程属于不同操作。被历史会话引用的版本保持可读。

定制选题使用 `sentence_bank_entry`，按稳定句子 ID 保存当前可选版本和发布状态。课程版本继续引用其固定题目版本。新版发布时更新可选指针及标签索引。撤下题库条目时暂停新定制会话选入，历史会话保持可读。发布检查验证考试标签、难度和词汇门槛的有效值。

## 接口

| 方法与路径 | 契约 |
| --- | --- |
| `GET /courses?examTrack=...` | 游客和账号可读，支持按考试路径过滤已发布课程 |
| `GET /courses/{id}` | 返回课程、课节顺序、题数与当前身份进度摘要 |
| `GET /me/courses` | 查询当前身份已练课程，附最近课节与进行中会话入口 |
| `POST /admin/lessons/{id}/drafts` | P1，管理员创建草稿版本 |
| `POST /admin/lesson-drafts/{id}/publish` | P1，按草稿修订号校验并事务发布 |

种子导入以稳定标识去重。回归场景覆盖重复发布、两个管理员同时发布、下架后继续已开始的会话，以及课程和未作答接口的响应中没有完整参考答案。
