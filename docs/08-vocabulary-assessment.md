# 词汇量测试

## 用户流程和测量对象

入口为目标选择后的「测词汇量」和学习概览中的「重新测评」。游客和账号均可使用。用户可以跳过，直接开始基础练习。首发快速测评为 36 题，目标耗时约 6–8 分钟，题目一页一题，显示进度，支持刷新续答。允许选择「不认识／不确定」，计为 0 分。提交后锁定该题，整轮完成时给出分频段结果、建议起点和「开始定制练习」入口。中途可退出再继续，最后一题提交后立即生成结果。

测评估算**书面接受性词汇**，以 **word family（词族）** 为单位。一个词族按所选版本的分组定义包含其词干和归组词形。词族抽样、多项选择和频段覆盖参考 Nation 的 VST 方法。产品使用自有题目、抽样和换算规则。测评与真实考试成绩、主动词汇和英文写作能力使用各自指标。[Victoria University of Wellington 词汇测试资源](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/vocabulary-tests) · [Nation 的 VST 规格](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/vocabulary-tests/the-vocabulary-size-test/Vocabulary-Size-Test-information-and-specifications.pdf)

## 出题方式

- 选定可用于项目的频率词族表，记录来源、使用许可、版本、词族归组规则和每档规模。P0 覆盖最高频的前 6,000 词族，分成六个 1,000 词族的频段，由每段抽 6 题。整个测试包含所有频段。
- 每个题为一个目标词、一条原创短语境、四个同词性且经人工审定的中文释义选项和独立的「不认识／不确定」。短语境帮助判定义项，避免直接给出线索。题目入库前复核选项歧义、词频和来源。备考词表可用于训练挑题和讲解。
- 初版按每档至少 18 个不同词族建设，共至少 108 道审核题，形成三套互斥的候选题。开测时固定题集版本、题目顺序、选项顺序和分段用途。同一学习者优先轮换未用题集，耗尽后循环。频段混合出题。目标考试只影响测后推荐，测评题型与算法在各路径统一。
- 每次从覆盖该频段的样本题中抽测。编辑仅从频率词族总表中筛掉难以公平命题的词时要记录筛除原因和分布。试测比较题集间难度与重测稳定性。管理员可撤下异常题，已开测会话保持原试卷和算法。

## 估算和起始词汇档

设频段 `i` 四选一中答对 `cᵢ` 题，明确点「不认识／不确定」`uᵢ` 题。初版估算公式如下。

```text
每段答对率     = cᵢ / 6
每段猜测校正后比例 = clamp((cᵢ - (6 - uᵢ) × 0.25) / (6 × 0.75), 0, 1)
估算词族数     = Σ(每段猜测校正后比例 × 1000)
```

这里假设未掌握且作答时在四选项间随机猜测，`0.25` 是该假设下的机会正确率。每段只抽 6 题，校正值用于起始推荐，稳定性需通过产品试测验证。若六段答对 `[6,5,4,3,2,1]` 且均未选「不认识」，估算约 2,778 词族，起始档为 V2。

| 档位 | 内部未舍入估算区间 | 推荐含义 |
| --- | --- | --- |
| V1 | 低于 1,500 | 优先高频词汇 |
| V2 | 1,500 至低于 3,000 | 扩展基础搭配和熟悉主题 |
| V3 | 3,000 至低于 4,500 | 增加低频词与主题表达 |
| V4 | 4,500 至 6,000 | 可尝试高级词汇与更丰富的主题 |

- 结果页以频段答对情况与建议档为主。试测阶段先显示档位；校准后开启数值展示，将未舍入估算按 500 词族划分展示区间。例如 2,778 显示为「约 2,500–3,000 词族」。该区间表示结果的展示粒度，界面同时标明覆盖前 6,000 词族。命中上限信号时以覆盖上限提示代替估算区间。
- 第六段至少 5/6 且全卷至少 33/36 时标记 `AT_CEILING`，显示「接近本测试覆盖上限」，归 V4。任一较高频段的答对数比较低频段少至少 3 题时标记 `UNSTABLE`。同时命中时优先标记 `UNSTABLE`，保留两项信号，起始词汇档下调一档，最低为 V1。其他结果为 `STANDARD`。这些是运营判定阈值。
- 试测覆盖目标用户和四条备考路径，检查四选项质量、题集难度差、重测一致性及推荐后的首答正确率。建议至少 100 名完成者，另收集不同档位的重测样本。随机分配试卷并对照首次测评人群；题集均分差超过 3 题时先排查题目和样本差异。开放数值前把可用词表、近似代表性、题集差异与重测结果写入校准记录。证据不足时保留分档推荐。后续评估拓展 6,000 以上频段。

## 接口和数据

| 方法与路径 | 契约 |
| --- | --- |
| `POST /vocabulary-assessments` | `{requestId}`。复用当前学习者进行中的测评，否则创建新测评。 |
| `GET /vocabulary-assessments/{id}` | 返回当前题、已答数、总题数和修订号。选项只含展示值和不透明 ID。 |
| `POST /vocabulary-assessments/{id}/answers` | `{requestId,revision,itemId,optionId}`。提交一题并推进；末题同事务生成结果，完成前服务端响应仅返回推进后的试卷视图。 |
| `GET /vocabulary-assessments/{id}/result` | 仅已完成且归属当前学习者时返回各段统计、`vocabBand`、结果质量、覆盖上限和算法版本。已启用数值展示且未达到覆盖上限时附估算区间。 |
| `GET /me/vocabulary-assessments` | 分页获取个人历史。个人推荐使用最新完成结果，按 `completedAt, id` 排序。 |

数据包括 `vocab_item_version`、`vocab_form_version`、`assessment_session`、`assessment_item`、`assessment_answer` 和 `assessment_result`。会话固定词表、题集与评分版本，记录顺序、题项、作答和幂等请求。当前学习者最多有一个活动测评，每题最多一条最终作答。写操作按学习者和会话加锁，重试按请求号返回原响应。题目选项、测评和结果均校验服务端归属，题库答案和内部题目统计只供授权服务读取。

验收覆盖中途退出续测、并发重复答题、没有泄露正确选项、全部选择「不认识」得到 V1、公式样例、上限和不稳定信号、题集换版、游客结果迁移以及跳过测评后直接进入定制训练。
