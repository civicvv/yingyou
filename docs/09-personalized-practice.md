# 定制练习与推荐

## 从诊断到练习

用户选择备考目标后，可以做词汇测试，也可以直接开始。个人学习页显示目标、建议整句难度和本批练习的选题依据，例如「四级 · 基础搭配 · 补练因果表达」。学习者可切换目标或主动改难度。每批默认 10 道题，创建时固定题目版本和排序，使用基础练习的词级反馈、整句判分和讲解。

词汇档 `V1–V4` 约束题目词汇门槛，整句难度 `D1–D4` 同时受句法和练习表现影响。首次将 V1 → D1、V2 → D2、V3 → D2、V4 → D3。V3 与 V4 都需要练习表现证明可以继续爬坡。没有有效测评时使用 V1 词汇门槛和 D1 起步，用户可手动选择难度。该映射适用于所有考试目标。由于考试路径的题目话题不同，即使难度相同也会抽到不同内容。

## 选题规则 v1

1. 读取当前目标、最新完成的测评档、有效的难度设定与该目标的练习证据。优先恢复同一目标的进行中定制会话。
2. 从已发布、允许新开练的题目版本筛选当前考试路径和 `GENERAL`。同一稳定句子只入选一次。除挑战槽位外，`minVocabBand` 不高于有效词汇档；挑战槽位最多高一档。不同考试目标的专属题各自隔离。
3. 按槽位挑题，默认 6 道当前档、3 道低一档巩固、1 道高一档挑战。触到 D1 或 D4 边界时，将超界槽位补到当前档。考试路径中优先选目标路径题，目标路径题至少占实际批次的一半。若库存无法满足该比例但可生成足够题量，则在启动页提示会含更多通用练习。
4. 每槽位按与目标匹配、近期相对薄弱的主要技能、最近一次练习距离、稳定 ID 排序。只有同一目标及当前难度的技能至少积累 3 道首答证据才用于排名；证据不足时优先保证主题多样性。默认过滤最近 7 天已练的同一稳定句子。最少覆盖两个主题（有供给时）。
5. 对缺口先使用同档通用题，再使用相邻较低难度题，之后放宽近 7 天去重，优先选最久未练的题。每一步仍保留词汇上限、题库可用性及批内去重。能选 5–9 道时返回较短批次并显示实际题数；少于 5 道时返回 `INSUFFICIENT_PRACTICE_ITEMS`，提供已发布课节入口。
6. 保存选择所用的目标、诊断、基线难度、规则版本、补位原因和已选版本。网络重试、页面刷新或新测评完毕均复用同一已创建批次。新批次采用更新的档位与规则。

## 难度更新

- 自动调整以当前目标的已完成定制会话为输入。每次用最近两批、基线等于当前档的当前档题计算窗口，最少 10 个互不重复的稳定句子。重复句取最近一次。跳过、使用辅助后才第一次答对、首答错误均计为未独立首答正确。直接通过的标准与课节统计共用。
- 首答独立正确率达到 80% 时升一档，低于 55% 时降一档，其余持平。只在下一批创建时生效。每批结束只评估一次，每次最多移动一档。升降后新的难度需重新积累同档窗口。对原指标缺失的历史批次从当前规则开始累积。
- 用户手动设置 `D1–D4` 时，下一批优先用手动值，关闭自动升降，直至恢复自动。设置高于词汇档对应起点时保留该词汇门槛并尝试合适的句法难度，缺题时按既定规则补位。
- 完成新测评后保留进行中的批次。下一批更新词汇门槛。当前目标已有有效训练证据时，保留基于练习的自动整句档；证据不足时按新的词汇档重新计算。切回其他目标时恢复该目标上次的难度和进行中会话。账号迁移时已保存的账号目标优先，双方练习归并后按事实重算。

## 数据与接口

- `learner_exam_preference` 记录当前目标。每个目标的 `learner_track_placement` 保存自动难度、手动设定、当前规则版本及最后评估会话。可基于测评结果和练习事实重建自动状态。
- 定制练习使用 `practice_session.source = PERSONALIZED`。会话无课节外键，题目版本仍落在 `practice_item`，选题快照 `practice_selection` 保存目标代码、诊断 ID、词汇档、基线难度、规则版本和补位原因。每个学习者每个目标最多一个活动个性化会话。场景成绩独立汇总；满足错题收录条件的题目进入错题本，记录考试目标来源。
- 默认可解释排序，无外部生成服务。指标记录完成率、独立首答率按档位分布、词汇测评转练习率和题量不足率，用于调阈值和补题。

| 方法与路径 | 契约 |
| --- | --- |
| `GET /me/learning-preferences` | 返回当前考试目标、词汇档、自动难度、手动设置和最近测评时间 |
| `PATCH /me/learning-preferences` | `{requestId,revision,examTrack?,difficultyMode?,manualDifficulty?}`。校验目标与版本；只影响尚未创建的批次 |
| `POST /personalized-practice/sessions` | `{requestId,examTrack?}`。未指定时使用当前目标或通用路径；创建或恢复该目标的会话，返回实际题数、选题依据和练习入口 |
| `GET /practice/sessions/{id}/result` | 复用练习结果，定制场景展示该批次的目标、分档表现与下批建议 |

验收示例。雅思学术类学员测得 V2，首批基线 D2，题量足够时取 6 道 D2、3 道 D1 和 1 道 D3。两批积累 12 道不同的 D2 题，独立首答正确 10 道，下一批基线升至 D3。切到四级时从该路径的独立状态开始。另测未诊断直接练、手动难度、题库不足、批次冻结、快照恢复、跨目标历史隔离、定制错题进入复练及并发创建幂等。
